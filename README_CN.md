# 十字准星目标过滤器
[English](https://github.com/LitnhJacuzzi/CrosshairTarget-Filter/blob/master/README.md) | 简体中文
## 概述
这是一个能够让你的十字准星穿透**任何**配置中指定的实体或方块选中后面的可交互目标的 Minecraft 模组，依赖 **Cloth Config** 管理配置项。

> [!WARNING]  
> **此模组可能违反你所在的服务器规则，请自行承担使用风险！**
## 用法
实体/方块过滤器可以分别通过两个初始未分配按键的**按键绑定**快速开启/关闭。你可以使用白名单或黑名单来过滤实体和方块，白名单列表与黑名单列表分开存储，且只有当对应的过滤模式被选中时才会发挥作用。它们的过滤规则如下：  
 - 白名单 - **只有**此列表中存在的元素**才能**被十字准星选中。  
 - 黑名单 - 此列表中的元素**无法**被十字准星选中。

关于列表元素的命名规范，请往下阅读：
### 实体
实体可以按**类型**、**类别**以及**名称**三种方式过滤：  
 - 类型以 `<namespace>:<registryName>` 的格式指定，例如 `minecraft:pig` 表示过滤所有猪实体，它可以在 F3 调试界面的目标实体信息中找到。  
 - 类别以 `[<category>]` 的格式指定，例如 `[MONSTER]` 表示过滤所有敌对生物。  
   截至 26.2 版本，共有八种类别可供选择：
   ```
   MONSTER（敌对生物）
   CREATURE（被动生物）
   AMBIENT（蝙蝠）
   AXOLOTLS（美西螈）
   UNDERGROUND_WATER_CREATURE（发光鱿鱼）
   WATER_CREATURE（鱿鱼，海豚，鹦鹉螺）
   WATER_AMBIENT（鳕鱼，鲑鱼，热带鱼，河豚）
   MISC（玩家，村民，傀儡以及无生命实体）
   ```
   特别地，流浪商人属于 `CREATURE` 类别。
 - 名称以 `"<name>"` 的格式指定，例如 `"示例"` 表示过滤名字为 `示例` 的实体。
### 方块
方块只能按类型过滤，它可以在 F3 调试界面的目标方块信息中找到，示例格式为 `minecraft:stone`。
